Zomato Food Delivery Data Analysis

Project Overview

This project focuses on analyzing Zomato food delivery data using Python. It explores delivery patterns and examines how weather conditions, road traffic, and delivery distance are associated with delivery time.

Technologies Used

- Python
- Pandas
- NumPy
- Google Colab

Dataset

The dataset contains 45,584 food delivery records with information about:

- Delivery person details
- Weather conditions
- Road traffic density
- Restaurant and delivery locations
- Order details
- Delivery time

Analysis Performed

1. Dataset exploration
2. Data cleaning and handling missing values
3. Delivery time analysis
4. Weather conditions analysis
5. Road traffic analysis
6. Delivery distance calculation
7. Distance and delivery time correlation

Key Objectives

- Understand food delivery patterns.
- Calculate average delivery time.
- Study the relationship between weather and delivery time.
- Examine the impact of road traffic.
- Calculate approximate delivery distances.

Project Files

- "Zomato_Food_Delivery_Analysis.ipynb" – Main Python analysis notebook.
- "zomato.csv" – Dataset used for analysis.

Conclusion

This project provided practical experience in Python-based data analysis, data cleaning, statistical calculations, and extracting meaningful insights from real-world food delivery data.
